Code signing policy

IntuaCode's installers aren't code-signed yet. Each one can be checked instead: it has a published SHA-256, and a record signed by GitHub of the build that made it.

Because they're unsigned, Windows may say it protected your PC, and macOS may not open the app the first time. Check the download first (below); then, on Windows, choose More info → Run anyway.

How the installers are made

  • Only from this project's own source, in its public repository, by its GitHub Actions workflow (.github/workflows/desktop.yml). Nothing is built on anyone's own computer.
  • Each release lists every file's SHA-256 in SHA256SUMS.txt; the download section shows them too.
  • Each installer has a build-provenance record signed by GitHub, naming the workflow run and the commit that built it.

Checking a download

  • Windows (PowerShell): Get-FileHash .\IntuaCode_0.4.0_x64-setup.exe -Algorithm SHA256, then compare it with SHA256SUMS.txt or the download section.
  • Linux and macOS: sha256sum -c SHA256SUMS.txt --ignore-missing (macOS: shasum -a 256 -c).
  • Any system, with the GitHub CLI: gh attestation verify <file> --repo matthewvincentthomasmalone-ops/IntuiCode.

Code signing later

Windows code signing is planned once the project is established; the release workflow already has the step, switched off. When releases are signed, this page will say who signs them and with which certificate.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • No accounts, telemetry, analytics or advertising. The fonts, the Python engine and the code parsers are bundled.
  • Projects are kept on your computer: in folders you choose (desktop app) or in your browser's storage (browser version).
  • Programs you write and run, and commands you type in its terminal, use the network only as you write them to.
  • On Windows, the app's window is drawn by Microsoft Edge WebView2, part of Windows, which follows Microsoft's privacy statement.

More in the security policy, which also says how to report a problem privately.

Uninstalling

  • Windows: Settings → Apps → Installed apps → IntuaCode → Uninstall (or uninstall.exe in its folder). Your projects' folders are left as they are.
  • Linux: delete the AppImage, or remove the .deb or .rpm package with your package manager.
  • macOS: move IntuaCode from Applications to the Bin.
