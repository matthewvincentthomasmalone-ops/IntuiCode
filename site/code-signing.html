Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

IntuaCode is applying to SignPath Foundation for Windows code signing. Releases published once the project is accepted have signed Windows installers; earlier releases are unsigned, and every release, signed or not, can be checked as described below.

What is signed

  • Windows: the installers (IntuaCode_…_x64-setup.exe and IntuaCode_…_x64_en-US.msi), with the product name IntuaCode and that release's version.
  • Only binaries built from this project's own source, in its public repository, by its GitHub Actions workflow (.github/workflows/desktop.yml). Nothing is built or signed on anyone's own computer.
  • Every signing request is approved by hand, one release at a time.
  • macOS and Linux installers aren't code-signed. Like the Windows ones, each has a SHA-256 in SHA256SUMS.txt and a signed build-provenance record: gh attestation verify <file> --repo matthewvincentthomasmalone-ops/IntuiCode.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • No accounts, telemetry, analytics or advertising. The fonts, the Python engine and the code parsers are bundled.
  • Projects are kept on your computer: in folders you choose (desktop app) or in your browser's storage (browser version).
  • Programs you write and run, and commands you type in its terminal, use the network only as you write them to.
  • On Windows, the app's window is drawn by Microsoft Edge WebView2, part of Windows, which follows Microsoft's privacy statement.

More in the security policy, which also says how to report a problem privately.

Uninstalling

  • Windows: Settings → Apps → Installed apps → IntuaCode → Uninstall (or uninstall.exe in its folder). Your projects' folders are left as they are.
  • Linux: delete the AppImage, or remove the .deb or .rpm package with your package manager.
  • macOS: move IntuaCode from Applications to the Bin.
