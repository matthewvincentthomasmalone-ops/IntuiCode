Read and change code in plain language.

Select any part of a program and IntuaCode says it in sentences, right where it is. Change the sentences and it turns them back into exact code. Python, websites, C++ and Arduino, including code an AI wrote for you.

Download Open in your browser

The browser version needs nothing installed: your projects stay in your browser.

What it does

Unity

Real code in one pane. Select a part and press Translate to Plain Language Syntax: it becomes sentences, in green, in place. Original Code puts it back exactly as it was.

Split Mode

Write in sentences on the left and watch the code they make on the right, with why each line is written that way.

Interface or mechanics

Every part of a project is sorted into Interface & Display and Backend & Mechanics. One click shows only the side you care about.

Project Link

Use your website in the preview and the code behind what you click lights up pink: its page, its styles and the script that runs.

Bring your own code

Import a file, a folder or a .zip in any of 40 languages. Python, web pages, C++ and Arduino can be said in sentences; the rest is explained part by part.

Runs it for real

Python runs in the page; the desktop app uses your own Python, C++ compiler and Arduino tools, with a real terminal.

Download

The desktop app works offline and on real folders. Pick your system.

All files and earlier versions · Code signing policy

Check a download before you open it
  1. Compare its SHA-256 with the one shown above.
    Windows (PowerShell): Get-FileHash .\IntuaCode_x64-setup.exe -Algorithm SHA256
    Linux: sha256sum -c SHA256SUMS.txt --ignore-missing
  2. Or confirm it was built from this source by GitHub, with the GitHub CLI:
    gh attestation verify IntuaCode_x64-setup.exe --repo matthewvincentthomasmalone-ops/IntuiCode

Windows code signing is being set up through SignPath Foundation (see the code signing policy). Until a release is signed, Windows may say it protected your PC: choose More info → Run anyway once the checksum matches. On Linux, make the AppImage runnable with chmod +x, or install the .deb or .rpm.

Security and privacy

Your code stays with you

The browser version runs entirely in your browser and keeps projects there. The desktop app works on folders you choose. Nothing is uploaded.

No accounts, no tracking

No sign-up, no analytics, no adverts. This page and the app load nothing from other sites, not even fonts.

Open source

Every line is public under the Apache 2.0 licence, and every installer is built from it by GitHub, in the open.

Downloads you can check

Each release lists a SHA-256 checksum for every file and carries a signed record of the build that made it.

Programs kept apart

Web pages you build run in a sealed preview that can't reach the editor or your files. The desktop app only opens folders you pick.

Report a problem

Found a security issue? Our security policy says how to tell us privately.
